# 课题组网页本地预览使用说明

## 打开预览

在项目目录运行 `python -m scripts.run_news_preview`。首次启动会复制一份站点内容到本机预览目录，并在启动终端显示账号文件的完整路径。Windows 的默认文件是 `%LOCALAPPDATA%\OPTICompt Lab\News Preview\preview-credentials.json`。

- 公开首页 [localhost:8000](http://localhost:8000/)
- 新闻编辑后台 [localhost:8000/editor](http://localhost:8000/editor/)
- 账号 `editor` 用于新建、发布和撤回新闻。`owner` 另外可以管理脚本凭证。各账号的本地预览密码在账号文件对应字段里。

本阶段可以试用首页与新闻。人员、论文及论文补充材料的上传在后续阶段验证。

## 人工发布一条新闻

1. 用 `editor` 登录，点「新建新闻」。填写日期，以及同一语言的标题和正文。摘要和一张配图可选。配图支持 5 MiB 以内的 PNG、JPEG 或 WebP。
2. 点「保存草稿」，再点「预览已保存的草稿」。在预览页检查标题、日期、正文和配图。改内容时点「返回编辑」，保存后再预览。
3. 确认后点「发布这版新闻」。返回新闻列表，打开该条的「公开页面」核对结果。要下线时回到编辑页，点「撤回发布」。撤回后仍可在后台编辑和重新发布。

## 让 Agent 生成新闻预览

平时给 Agent 一句话，并让它读本说明。例如「请把我本地的 `D:\课题组\新闻稿.md` 和 `D:\课题组\合照.jpg` 上传到课题组网站，给我预览。」

### 首次设置脚本凭证

由站点所有者用 `owner` 登录，在「脚本凭证」页生成凭证。页面只展示这次新生成的值。把它保存在 Agent 运行环境的密钥设置里，供本地命令通过 `OPTICOM_DRAFT_TOKEN` 环境变量读取。手动运行命令时，也可按终端提示输入凭证，输入会隐藏。生成新凭证会替换旧凭证。撤销后应从运行环境移除旧值。

### Agent 操作规范

1. 找到并读取用户指定的材料。如有多份同名文件，请先确认使用哪一份。按下表整理稿件，保留原文中的事实和语言版本。源文件缺少的翻译、日期或摘要可以留空，在报告中提示补齐。标题缺失时向用户确认。
2. 在项目目录之外把新闻字段保存为 UTF-8 JSON 对象。将配图原文件路径交给脚本。脚本的 `--image` 参数可省略。新闻字段和图片相同的重试会取回同一次提交，以便恢复网络中断。
3. 在项目目录运行下方的脚本。命令成功时从 JSON 读取 `created`、`preview_url` 和 `id`。失败时报告命令给出的错误，拿到有效链接后才能报告提交成功。此流程可在终端完成。需要展示预览时才打开浏览器。若页面要求登录，用 `editor` 登录后会直接回到对应草稿的预览。
4. 给用户一份短报告，写清用了哪些源文件，创建了草稿还是取回了上次提交，哪些字段待确认，以及预览链接。发布由内容编辑在预览页确认。

| JSON 字段 | 内容 |
|---|---|
| `title_zh` / `title` | 中文 / 英文标题。至少有一个，最多 220 字符。 |
| `content_zh` / `content` | 中文 / 英文正文。保留段落换行，每项最多 20,000 字符。发布须有同一语言的标题和正文。 |
| `date` | 新闻日期，格式是 `YYYY-MM-DD`。源文件未给日期时可留空，发布前由编辑补齐。 |
| `summary_zh` / `summary` | 可选的中文 / 英文摘要，每项最多 700 字符。 |
| `pinned` / `hide_from_home` | 可选布尔值。分别控制置顶和是否在首页隐藏。省略时均为 `false`。 |

### 可以直接试用的例子

把以下内容保存为项目目录之外的 `draft.json`。这是本地测试稿，下一步中的 `news_003.jpg` 用于试验配图。

```json
{
  "title_zh": "课题组网页本地预览测试",
  "date": "2026-11-25",
  "summary_zh": "验证带图新闻的草稿提交流程。",
  "content_zh": "这条稿件用于本地试验。\n\n请核对预览中的日期、段落与配图。"
}
```

把命令中的路径换成实际的文件路径。在项目目录运行：

```powershell
python -X utf8 -m scripts.upload_news_draft 'D:\临时素材\draft.json' --image 'site_content/images/news/news_003.jpg' --site 'http://localhost:8000' --json
```

示例报告可以写成「已从 `新闻稿.md` 和 `合照.jpg` 创建新闻草稿。日期待核对。请打开预览链接，确认后在后台发布。」把实际的 `preview_url` 一并发给用户。

论文阶段会单独约定如何读取本地论文和补充材料、哪些字段要核对、各类附件如何提交，并用真实样例计时验收到预览的全流程。
